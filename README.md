# ClassOS

Welcome to **ClassOS**.

Version 1 is located in [`classos-v1/`](classos-v1/).

## Quick Start (V1)
```bash
cd classos-v1
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m app.main
```

Refer to [`classos-v1/README.md`](classos-v1/README.md) for complete documentation, keyboard shortcuts, and testing instructions.
